# Étape 05 — Tests pytest

## Contexte

On écrit une suite de tests complète avec fixtures, parametrize et mocks.

## Consignes

1. Créer `conftest.py` avec fixtures partagées.
2. Utiliser `@pytest.mark.parametrize` pour les cas invalides.
3. Utiliser `monkeypatch` ou `unittest.mock` au moins une fois.
4. Au moins 10 tests au total.

## Critères d'acceptation

- [ ] `conftest.py` avec au moins 2 fixtures.
- [ ] `@pytest.mark.parametrize` utilisé.
- [ ] Mock utilisé au moins une fois.
- [ ] `pytest -v` vert.
