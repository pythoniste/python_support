# Initiation Python — 3 jours

**Cible :** débutant Python (éventuellement développeur d'un autre langage).
**Objectif :** écrire des scripts Python autonomes, manipuler des données basiques, livrer un mini-projet.
**Fil rouge :** 📝 Carnet de recettes (voir `Fil_rouge/README.md`).

> Version compressée de l'Initiation 5 jours. Les notebooks sont **générés automatiquement** depuis les notebooks 5 j via `tools/build_3j.py` qui retire les cellules tagguées `skip-3j`, `exo-difficile`, `deep-dive` et `bonus`.

## Programme jour par jour

### J1 — Syntaxe & types
- **Matin :** Installation, variables, types primitifs, opérateurs · Conditions, boucles
- **Après-midi :** Listes, tuples, dicts · Chaînes et f-strings
- **Étapes fil rouge :** 01 (matin), 02 (après-midi)

### J2 — Fonctions & fichiers
- **Matin :** Fonctions, paramètres, retours · Exceptions basiques
- **Après-midi :** Fichiers texte + `pathlib` · CSV · JSON
- **Étapes fil rouge :** 03 (matin), 04 (après-midi)

### J3 — Modules & livrable
- **Matin :** Modules standard, imports, organisation
- **Après-midi :** `pyproject.toml` minimal + entry point · Finalisation fil rouge
- **Étapes fil rouge :** 05 (matin), 06 (après-midi)

## Fil rouge

Le dossier `Fil_rouge/` contient le projet Python classique (6 étapes) avec `ENONCE.md`, `starter/` et `solution/` par étape.
